FAQ & Troubleshooting

Find quick answers to common issues, error codes, and configuration tips for ModelDock.

Common Troubleshooting Solutions

1. Port 7860 is Already in Use

If another service (e.g. Gradio, WebUI) is already listening on port 7860, ModelDock allows you to customize the port in config.json:

config.json 
{
  "server_port": 8090,
  "server_host": "127.0.0.1"
}

2. NVIDIA GPU Not Detected / CPU Fallback

If ModelDock falls back to CPU despite having an NVIDIA card:

  • Ensure you have the latest NVIDIA Game Ready or Studio Driver (Version 535+).
  • Open Windows Terminal and run nvidia-smi to verify the driver is active and reporting VRAM.
  • Check Settings → Compute & Hardware in ModelDock and ensure GPU mode is set to Auto or CUDA.

3. Hugging Face 401 Unauthorized Error

This occurs when attempting to download gated models (such as Llama 3 or Gemma 2) without an authenticated token:

  1. Visit the model's page on Hugging Face in your browser and ensure you have accepted the license agreement terms.
  2. Generate a User Access Token with read scope at huggingface.co/settings/tokens.
  3. In ModelDock, paste the token in Settings → Auth & Keys and click Verify & Save.

4. Out of Memory (CUDA OOM)

If the inference engine fails to load a model with an out-of-memory error:

  • Select a more compact quantization tier (e.g. Q4_K_M instead of Q8_0 or FP16).
  • Reduce the context length (e.g., from 8192 to 4096 or 2048 tokens).
  • Reduce the number of offloaded GPU layers in Settings so that part of the model runs in system RAM.

Frequently Asked Questions

Does ModelDock send any of my data or prompts to the cloud?

No. ModelDock is 100% local and private. All model weights, inference computations, and chat histories reside entirely on your physical machine. Outbound network traffic is only initiated when you explicitly search or download weights from Hugging Face or Ollama.

Can I run ModelDock completely offline (air-gapped)?

Yes. Once you have downloaded or imported your .gguf model weights, ModelDock operates entirely without an active internet connection.

What licenses apply to models downloaded through ModelDock?

Each model maintains its creator's respective open-source license (such as Apache 2.0, MIT, Llama 3 Community License, or Gemma Terms of Use). ModelDock itself is licensed under the permissive Apache 2.0 License.
