Core Features

Engineered from the ground up for raw performance, zero bloat, and seamless local AI developer workflows on Windows.

1. Ultra-Low RAM Footprint (~35 MB)

Running open-source large language models requires substantial memory. A 7B parameter Q4_K_M model requires roughly 4.5 GB of RAM/VRAM, while a 14B model requires 9 GB+.

Traditional AI desktop interfaces bundle Electron (which packages an entire standalone Chromium browser and Node.js runtime). This often consumes 600 MB to 1.5 GB of RAM before loading a single byte of model weights.

ModelDock resolves this bottleneck by adopting Microsoft Edge WebView2 and an asynchronous Python/FastAPI micro-engine:

  • Idle Memory: Consistently maintains ~30 MB to 40 MB RAM.
  • Zero CPU Idle Overhead: 0.0% CPU usage while awaiting prompts.
  • Resource Prioritization: Virtually 100% of available physical memory is reserved for the model's KV cache and model parameters.

2. Standalone Inference Engine (Zero Daemon)

ModelDock does not require an external daemon or background service. It bundles optimized llama.cpp binaries (located in bin/llama-server.exe) directly inside the repository:

No External Ollama Daemon Required

If you have Ollama installed, ModelDock can interface with it. But if you don't, ModelDock automatically launches its standalone llama.cpp process upon request and terminates it cleanly when finished, leaving zero ghost processes.

3. True Resumable Downloads (HTTP Range)

Downloading 4 GB to 40 GB model files across consumer internet connections is prone to packet drops, throttling, or accidental interruptions.

ModelDock's download manager implements strict HTTP Range byte-level streaming:

  • Pause Anytime: Pressing Pause cleanly closes the socket while saving the downloaded byte offset.
  • Resume Without Loss: Pressing Resume sends an HTTP header Range: bytes={current_size}-, picking up exactly where it left off without discarding downloaded megabytes.
  • Progress Telemetry: Real-time download rate (MB/s), downloaded percentage, ETA calculation, and total byte verification.

4. Multi-Modal Documents & Vision Processing

ModelDock includes a built-in document processor (core/media_processor.py) and visual synthesis engine:

  • Drag-and-Drop Files: Attach PDFs, Microsoft Word (.docx), plain text files (.txt, .md, .py, .json), and images (.png, .jpg, .webp).
  • Text Extraction: Automatic text extraction, page splitting, and token-aware context injection.
  • Vision Models: When paired with vision-capable GGUF models (such as LLaVA or Qwen2-VL), image attachments are fed directly into the model's visual projection layers.

5. Real-Time Streaming Chat Playground

The built-in chat interface provides instant feedback for model testing:

  • Token Streaming: Sub-second Time-To-First-Token (TTFT) and smooth character-by-character generation.
  • Live Telemetry: Live metrics displayed per response: generation speed (tokens/second), total tokens generated, and prompt evaluation latency.
  • Markdown & Code Rendering: Automatic syntax highlighting, code snippet formatting, and 1-click copy buttons.
  • Custom System Prompts: Fine-tune temperature, context window size (e.g. 2048, 4096, 8192, 16384), and persona instructions on the fly.
