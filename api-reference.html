OpenAI-Compatible Local API (/v1)

ModelDock exposes a fully compliant OpenAI REST endpoint at http://localhost:7860/v1, enabling zero-configuration integration with external AI developer tools.

Connection Configuration

Setting Value Description
Base URL http://localhost:7860/v1 OpenAI-compatible local root endpoint
API Key none (or any dummy text) Auth header accepted but not required locally
CORS * (Allowed across all origins) Supports web apps, browser extensions, and local ports

Supported Endpoints

1. List Models

GET /v1/models

Returns all currently docked and available local models in standard OpenAI JSON format.

cURL Example 
curl http://localhost:7860/v1/models

2. Chat Completions

POST /v1/chat/completions

Supports both streaming Server-Sent Events (stream: true) and standard JSON response (stream: false). 

from openai import OpenAI

# Initialize client pointing to ModelDock
client = OpenAI(
    base_url="http://localhost:7860/v1",
    api_key="none"
)

# Stream response tokens live
stream = client.chat.completions.create(
    model="local-model",
    messages=[
        {"role": "system", "content": "You are a concise engineering assistant."},
        {"role": "user", "content": "Explain what a GGUF file is in 2 sentences."}
    ],
    temperature=0.7,
    stream=True
)

for chunk in stream:
    if chunk.choices[0].delta.content is not None:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()
import OpenAI from "openai";

const openai = new OpenAI({
  baseURL: "http://localhost:7860/v1",
  apiKey: "none"
});

async function main() {
  const completion = await openai.chat.completions.create({
    model: "local-model",
    messages: [{ role: "user", content: "Write a quick hello world in Rust." }],
    stream: true,
  });

  for await (const chunk of completion) {
    process.stdout.write(chunk.choices[0]?.delta?.content || "");
  }
}

main();
curl -X POST http://localhost:7860/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "local-model",
    "messages": [
      {"role": "user", "content": "What is 42?"}
    ],
    "temperature": 0.7,
    "stream": false
  }'

Third-Party Tool Configuration

Connect your favorite local AI tools in seconds:

Cursor IDE

Open Cursor Settings → Models → OpenAI API Key:

  • Base URL: http://localhost:7860/v1
  • API Key: none
  • Model Name: Enter the name of your loaded model (or leave default).

VS Code Continue Extension

Add the following configuration block to your ~/.continue/config.json:

JSON 
{
  "models": [
    {
      "title": "ModelDock Local",
      "provider": "openai",
      "model": "local-model",
      "apiBase": "http://localhost:7860/v1",
      "apiKey": "none"
    }
  ]
}

OpenWebUI

Under Admin Panel → Settings → Connections → OpenAI API:

  • URL: http://localhost:7860/v1
  • Key: none
  • Click Verify Connection. OpenWebUI will pull all docked models instantly!
