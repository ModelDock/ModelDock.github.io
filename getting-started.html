Getting Started

Learn about system requirements, 1-click installation on Windows 10/11, launching modes, and how to verify your local engine setup.

System Requirements

ModelDock is designed for maximum efficiency on Microsoft Windows operating systems:

Component Minimum Requirement Recommended Configuration
Operating System Windows 10 64-bit (Version 1909+) Windows 11 64-bit (22H2 or newer)
Processor (CPU) Intel Core i5 / AMD Ryzen 3 (AVX support) Intel Core i7/i9 or AMD Ryzen 7/9 (AVX2 / AVX512)
System Memory (RAM) 8 GB RAM (runs 1B - 3B models) 16 GB - 64 GB RAM (runs 7B, 14B, 32B models)
Graphics (GPU) Integrated GPU / CPU only fallback NVIDIA RTX 3060 / 4060 or higher (CUDA 12+)
Python Runtime Python 3.10 64-bit Python 3.11 or 3.12 (with pip installed)
Storage 500 MB for app + model storage space Fast NVMe SSD for fast GGUF weight loading

Launching ModelDock

ModelDock offers two distinct launching modes to fit your preferred workflow:

Mode 1: Native Windows Desktop App (Recommended)

Double-click Launch-Desktop.bat. This starts the backend asynchronously and opens a native Windows window powered by Microsoft Edge WebView2:

Batch / CMD 
Launch-Desktop.bat
WebView2 Advantage

WebView2 uses the Windows OS-provided evergreen web engine, eliminating the need to bundle Chromium or Node.js. Your app window opens with native Aero borders and memory usage stays at ~35 MB.

Mode 2: Web / Browser Interface

If you prefer accessing ModelDock directly in your default browser (Chrome, Firefox, Edge, Brave), execute:

Batch / CMD 
run.bat

# Or directly via Python
python run.py

ModelDock will automatically start on http://localhost:7860 and launch your default browser tab.

1-Click Windows Installation (Install.bat)

To register ModelDock as an official installed application in Windows:

  1. Right-click Install.bat and select Run as administrator (or run it from your command prompt).
  2. The installer performs the following actions automatically:
    • Validates Python 3.10+ installation.
    • Installs all required dependencies (FastAPI, Uvicorn, PyWebView, Requests).
    • Creates desktop shortcut with the official high-resolution app.ico icon.
    • Adds ModelDock to your Windows Start Menu programs folder.
    • Registers uninstallation metadata in Windows Registry so it appears under Installed Apps.
Uninstallation

To uninstall ModelDock, go to Windows Settings → Apps → Installed Apps → ModelDock → Uninstall, or execute Uninstall.bat.

First Launch Checklist

Once you open ModelDock for the first time:

  • Verify Hardware Telemetry: Check the header telemetry bar. ModelDock will report detected CPU threads, available RAM, and GPU VRAM.
  • Configure Directories (Optional): In Settings, you can specify custom storage paths for downloaded models (e.g. an external SSD: D:\AI_Models).
  • Hugging Face Token: If you plan to download gated models like Meta Llama 3 or Mistral, paste your Hugging Face User Access Token in Settings → Auth & Keys.
