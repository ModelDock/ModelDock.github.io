Model Hub & Downloads

Search Hugging Face Hub, understand quantization formats, authenticate gated model access, and pull from the Ollama model library.

1. Hugging Face Hub Live Search

ModelDock connects directly to the official Hugging Face Hub REST API with zero proxy latency. In the Hub tab, you can search for any model creator or architecture (e.g., meta-llama, Qwen, bartowski, mistralai, google/gemma-2):

  • Automatic GGUF Filtering: ModelDock identifies repos containing .gguf weights.
  • File Tree Inspection: Expands and presents all available quantization files with their exact file sizes (e.g. model-q4_k_m.gguf (4.37 GB)).
  • 1-Click Download: Clicking download streams the file directly into your configured downloads/ folder with instant telemetry.

2. Understanding Quantization Tiers

GGUF files are quantized to reduce memory usage and increase inference tokens-per-second with minimal loss in reasoning capability:

Quantization Bits / Weight VRAM Required (7B) Perplexity / Quality Best Use Case
Q4_K_M ~4.5 bpw ~4.5 GB Near-baseline (<0.1% loss) Recommended Default: Ideal balance of speed, RAM, and intelligence.
Q5_K_M ~5.5 bpw ~5.6 GB Near-perfect Enhanced reasoning for complex math and code generation tasks.
Q8_0 8.0 bpw ~8.5 GB Indistinguishable from FP16 Maximum precision for production evaluation and research benchmarks.
Q3_K_M ~3.4 bpw ~3.8 GB Noticeable degradation Low-spec hardware (8 GB system RAM or 4 GB VRAM laptops).

3. Gated Models & Hugging Face Auth

Leading frontier weights like Meta Llama 3.1 / 3.2 and Google Gemma 2 require agreeing to their license agreement on Hugging Face before downloading.

To access gated models in ModelDock:

  1. Create or log into your account at huggingface.co.
  2. Accept the terms on the model's official repository (e.g. meta-llama/Llama-3.2-3B-Instruct).
  3. Generate a User Access Token (Read permissions) at huggingface.co/settings/tokens.
  4. In ModelDock, navigate to Settings → Auth & Keys, paste your token (starts with hf_...), and click Verify & Save.
Token Security

Your access token is stored locally in config.json on your machine and is never sent to third-party tracking services or external servers—only directly to Hugging Face's HTTPS endpoints.

4. Ollama Registry Pulling

ModelDock also supports pulling models directly by their Ollama tag:

  • Enter any popular tag in the Hub search bar, such as: mistral:latest, qwen2.5:7b, deepseek-r1:8b, phi3:mini.
  • ModelDock delegates the layered download to the engine and monitors chunk transfer progress.

5. 1-Click Local GGUF Import

Already have .gguf files stored on your hard drive or an external SSD? You do not need to re-download or duplicate them:

  1. Go to the Models tab.
  2. Click Import Local .GGUF.
  3. Select your .gguf file.
  4. ModelDock inspects the file header, parses metadata (context length, architecture, tensor format), and instantly docks it into your local model library!
