REST Endpoints Reference

Comprehensive specification of ModelDock Studio's internal REST API endpoints for monitoring, model catalog control, downloads, and chat streaming.

System & Telemetry

GET /api/system/status

Returns live real-time hardware metrics for CPU, RAM, and GPU VRAM.

Response JSON (200 OK) 
{
  "app_ram_mb": 34.8,
  "app_cpu_percent": 0.0,
  "system_ram": {
    "total_gb": 31.9,
    "available_gb": 22.4,
    "used_percent": 29.8
  },
  "gpu": {
    "detected": true,
    "name": "NVIDIA GeForce RTX 4070 Laptop GPU",
    "vram_total_mb": 8188,
    "vram_free_mb": 6240,
    "vram_used_mb": 1948
  }
}

Settings & Configuration

1. Get Configuration

GET /api/settings or GET /api/config

Retrieves user preferences and configuration with sensitive Hugging Face tokens masked.

2. Update Configuration

POST /api/settings/update

Request Body JSON 
{
  "cpu_threads": 8,
  "gpu_mode": "cuda",
  "gpu_layers": 33,
  "default_temperature": 0.7,
  "default_context_length": 4096,
  "system_prompt": "You are a helpful coding assistant."
}

Download Manager Endpoints

Method Endpoint Description
GET /api/downloads/status Returns state, speed, percentage, and bytes for all active tasks.
POST /api/downloads/pause Pauses an ongoing download cleanly, preserving HTTP Range offset.
POST /api/downloads/resume Resumes an active paused download without redownloading bytes.
POST /api/downloads/cancel Cancels download task and purges temporary files.

Model Catalog Endpoints

Method Endpoint Description
GET /api/models/list Returns all docked models with parameter size, quant format, and path.
POST /api/models/import-local Docks an existing local .gguf file into ModelDock catalog.
DELETE /api/models/delete Un-docks and deletes local model weights from disk.

Chat Streaming Endpoint

POST /api/chat/stream

Streams tokens using Server-Sent Events (SSE). Emits generation telemetry once completion concludes.

Request JSON 
{
  "model": "Llama-3.2-3B-Instruct-Q4_K_M.gguf",
  "messages": [
    {"role": "user", "content": "Explain recursion in one sentence."}
  ],
  "temperature": 0.7,
  "num_ctx": 4096
}
