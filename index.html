Next-Generation Local AI Platform

Universal Local AI Docking Station
Fast, Featherlight & Daemon-Free

Run any open-source AI model locally on CPU & GPU. Connects Hugging Face Hub and Ollama under one roof with resumable downloads, hardware acceleration, and ultra-low ~35 MB RAM footprint.

Quick Start Guide Explore OpenAI API

Why ModelDock?

Most local AI software bundles heavy Chromium or Electron runtimes, consuming 600 MB to 1.5 GB of RAM before you even load model weights. Other tools force developers into isolated silos (either strictly Ollama commands or manual unorganized GGUF downloads).

~35 MB RAM Footprint

Native Edge WebView2 runtime and async FastAPI architecture uses ~95% less RAM than Electron apps, leaving maximum VRAM/RAM for models.

Zero Daemon Dependency

Bundles standalone high-performance llama.cpp inference server binaries. No external Ollama background services or Docker daemons needed.

True Pause & Resume

Streams multi-gigabyte GGUF models from Hugging Face Hub using HTTP Range chunk headers. Pause anytime without losing already downloaded bytes.

OpenAI-Compatible Local API

Instant drop-in local endpoint (http://localhost:7860/v1) for Cursor, VS Code Continue, OpenWebUI, Cline, LangChain, and AutoGen.

Quick 1-Click Launch

Clone the repository or download the release package, then execute:

Windows Batch / Console 
# Launch native desktop app (Edge WebView2)
Launch-Desktop.bat

# Or run the browser studio interface
run.bat
Windows Desktop Registration

To register ModelDock in your Windows Start Menu, create desktop shortcuts, and register in Windows Add/Remove Programs, simply run Install.bat once as an administrator.
